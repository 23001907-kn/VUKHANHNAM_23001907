# Bài 2 — Đặt vé xem phim

Chạy trong thư mục `bai2`:

```powershell
npm.cmd install
npm.cmd run dev
```

Build: `npm.cmd run build`.

- `src/App.vue`: data, computed, methods và giao diện Vue.
- `src/main.css`: CSS xanh biển và trắng, bố cục responsive.
- `src/main.js`: khởi tạo ứng dụng bằng createApp.

Kiểm tra: nhập họ tên, chọn VIP, số lượng 2, chọn combo → tổng 245.000 ₫.
Số lượng chỉ hợp lệ khi là số nguyên 1–10. Đơn xác nhận giữ nguyên khi chỉnh sửa form; nút đặt lại xóa cả xác nhận.
Ứng dụng là bài thực hành, không lưu dữ liệu khi tải lại trang và không tạo giao dịch thực tế.
